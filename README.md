## 📖 Sobre este repositorio

Recopilación de **5 programas** que realicé en **Visual Basic 5.0** entre 1998 y 2001.
Dos de ellos fueron publicados en la revista **PCActual** y distribuidos en el CD que la acompañaba.

> ⚠️ **Archivo histórico:** solo se conservan los ejecutables compilados.
> El código fuente original se perdió, por lo que no hay código que revisar ni compilar.

## 📦 Programas

| Programa | Año | Descripción | Notas |
|----------|-----|-------------|-------|
| 🔒 **Protector de carpetas** | may. 1998 | Protegía carpetas con contraseña. | Publicado en PCActual nº 105 (con CD). **Obsoleto.** |
| 💶 **Euroconvert** | feb. 1999 | Convertía divisas europeas a euros y viceversa. | Publicado en PCActual nº 108 (con CD). |
| 👻 **La casa encantada** | jul. 1999 | Juego de lógica. | Hay una [versión actualizada](https://github.com/Zontrox01/LaCasaEncantada) en otro repositorio. |
| 🪪 **NIF** | abr. 2001 | Calcula la letra de un número de DNI. | |
| ⚓ **Pearl Harbour 1941** | jul. 2001 | Clásico juego de hundir la flota. | |

## 💻 Uso y requisitos

- Sistema operativo **Windows** (programas de finales de los 90 y principios de los 2000).
- Pueden necesitar el *runtime* de Visual Basic 5.0 (`MSVBVM50.DLL`).
- En versiones modernas de Windows, prueba el **modo de compatibilidad** (clic derecho → Propiedades → Compatibilidad).
- Descarga los ejecutables desde la sección [Releases](../../releases) o desde las carpetas del repositorio.

## ⚠️ Aviso

- **Protector de carpetas** está obsoleto y su sistema de protección no es seguro para los estándares actuales. **No lo uses para proteger información sensible.**
- **Euroconvert** incluye monedas europeas que ya no existen. Se conserva por su valor histórico.
